# One project path per line (relative to ${MAVEN_PROJECTS_DIR}, default `maven`).

# FLAKY_PROJECTS="" to disable per-project flaky handling.
#
# Document the actual cause of flakiness in ~/wrk/maven/maven-bugfixing/queue/
# before adding a project here -- the retry list is not a place to hide
# permanently broken projects.
