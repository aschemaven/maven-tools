# 4.x-native lines that need a git WORKTREE (Deliverable 3 / Phase 7).
#
# Most 4.x-native plugin lines are ALREADY checked out by the repo manifest as
# their own "-4" projects and are built by the normal matrix (and rendered in
# the "4.x-native lines" section by compat-render):
#     plugins/core-4/maven-clean-plugin      plugins/core-4/maven-compiler-plugin
#     plugins/core-4/maven-deploy-plugin     plugins/core-4/maven-install-plugin
#     plugins/core-4/maven-resources-plugin  plugins/packaging-4/maven-jar-plugin
#     plugins/packaging-4/maven-source-plugin  shared-4/filtering
# Those need NOTHING here.

# worktrees under maven-4x/<project>; bin/run-compat-4x then runs the matrix
# over them with MATRIX_NS=_4x so their cells render in the 4.x-native section.

# Format:  <project-path>            <4x-branch>
# Lines starting with # and blank lines are ignored.

# than master; site's 4.x line may live on master while its 3.x line is a -3.x
# branch. Confirm with `git -C maven/<project> branch -r` before trusting a row.
